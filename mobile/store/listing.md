## 설명 (App Store 설명 · Play 자세한 설명 공통)

여러 체험단 사이트를 하나씩 열어 보고, 가게 주소를 지도에서 다시 찾고 있나요?
리뷰맵은 20곳 이상의 체험단 사이트 모집 공고를 한곳에 모아, 내 주변 지도에서 바로 보여 드립니다.

■ 이렇게 사용해요
1. 지도 탭을 열면 내 주변에 모집 중인 체험단이 지도에 표시됩니다.
2. 지도를 원하는 동네로 옮기고 '이 위치로 검색'을 누릅니다.
3. 마음에 드는 공고를 누르면 해당 사이트의 신청 페이지로 이동합니다.

■ 주요 기능
· 지도 탐색: 화면에 보이는 범위의 체험단을 지도와 목록으로 함께 확인
· 카테고리: 맛집, 카페/디저트, 뷰티/헬스, 숙박, 여행, 문화/클래스 등
· 정렬: 최신등록순, 마감임박순, 거리순
· 한눈에 보는 정보: 제공 내역, 남은 마감일, 내 위치에서의 거리, 모집 채널
· 이용 가능 요일: 요일 정보가 있는 숙박·여행 공고는 이용할 수 있는 요일을 목록에서 바로 확인
· 키워드 알림: 동네나 메뉴를 등록해 두면 새 공고가 올라올 때 알림

■ 로그인
홈, 지도, 검색은 회원가입 없이 이용할 수 있습니다. 키워드 알림은 로그인 후 사용할 수 있습니다.

■ 접근 권한 안내
· 위치(선택, 앱 사용 중): 내 주변 체험단과 거리를 보여 주기 위해 사용합니다. 허용하지 않아도 지도를 옮겨 검색할 수 있습니다.
· 알림(선택): 키워드 알림을 보내기 위해 사용합니다.

■ 참고
· 모집과 선정은 각 체험단 사이트에서 진행합니다. 자세한 조건과 일정은 원본 페이지에서 확인해 주세요.
· 지도는 네이버 지도를 사용합니다.

## 이미지 만드는 방법

캠페인과 지도는 운영 API의 실제 데이터를 쓰고, 위치는 성수역으로 고정하며 광고는 끈다. 키워드·알림 화면만 예시 키워드를 쓰고 알림 항목은 실제 캠페인이다. 모두 `mobile` 폴더에서 실행하며, 만든 이미지(`store/ios`, `store/android`)는 커밋하지 않는다.

| 순서 | 명령 |
|---|---|
| 1. iOS 캡처 앱 빌드 | `flutter build ios --simulator --debug -t tool/store_screenshots_app.dart` |
| 2. iPhone 6.9인치 촬영 | `python3 tool/capture_screenshots.py <iPhone 16 Pro Max UDID> phone` |
| 3. iPad 13인치 촬영 | `python3 tool/capture_screenshots.py <iPad Pro 13 UDID> tablet` |
| 4. Android APK 빌드 | `flutter build apk --debug -t tool/store_screenshots_app.dart` |
| 5. Android 촬영 (에뮬레이터) | `python3 tool/capture_screenshots.py <시리얼> android_phone`, 태블릿 크기로 바꾼 뒤 `android_tablet` |
| 6. 이미지 합성 | `uv run --with pillow python tool/store_assets.py` |

캡처 중 화면에 오류가 하나라도 나면 스크립트가 멈춘다. 합성 결과는 올리기 전에 눈으로 확인한다.
